# دعوة خطوبة — علبة الخاتم (باقة عادية)

```
npm install
npm run dev
```

## القيم التجريبية: `src/config/invite.js`
الأسماء (ليلى/آدم)، حرفا الشعار، النص، التاريخ والوقت، اسم القاعة والمدينة، رابط الخرائط، الحد الأقصى للمرافقين.

## الصور: `public/assets` (الحالية بدائل مرسومة بالكود — استبدليها بنفس الأسماء)
- `arch.jpg`: القوس الملكي المورد فقط، بدون أشخاص (عمودي 9:16، مثلاً 1080×1920).
- `bride.png` و`groom.png`: PNG شفاف لكل شخص، وقفة جانبية ويد ممدودة نحو الوسط بدون ملامسة، حوالي 600×1100.
  العروس تواجه اليمين واليد على حافتها اليمنى، والعريس تواجه اليسار.
- بعد وضع صورك، اضبطي ارتفاع اليدين بالمتغير `--hands-y` في `styles.css` (أول `.page`) ليكون الخاتم المضيء بين اليدين تمامًا.
- أماكن النصوص الموزعة: `.date` و`.time` و`.place` في `styles.css`.
- الشعار: `components/Monogram.jsx` (حرفان داخل حلقة ذهبية) — استبدليه بشعار العميل إن وُجد.

## RSVP
واجهة أمامية فقط ولا تحفظ شيئًا. للربط لاحقًا بـ Firestore عدّلي `src/services/rsvpService.js`.
