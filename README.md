# دعوة خطوبة — علبة الخاتم (باقة عادية)

```
npm install
npm run dev
```

## القيم التجريبية: `src/config/invite.js`
الأسماء (ليلى/آدم)، حرفا الشعار، النص، التاريخ والوقت، اسم القاعة والمدينة، رابط الخرائط، رقم واتساب لتلقي الردود، الحد الأقصى للمرافقين.
- `placeName` و`mapsUrl` ما زالا قيمًا تجريبية ويجب استبدالهما قبل النشر.
- `whatsapp`: رقم بصيغة دولية بدون أصفار بادئة (مثال `218912345678`)؛ يظهر زر «رد عبر واتساب» تلقائيًا عند تعبئته، ويُخفى عند تركه فارغًا.

## الصور: `public/assets` (الحالية بدائل مرسومة بالكود — استبدليها بنفس الأسماء)
- `floral-arch-reference.png`: خلفية القوس المورد الحالية (مرجع مؤقت، يُفضّل استبدالها بصورة أخف حجمًا — الحالية حوالي ١.٩ ميجابايت).
- `client-logo.png`: شعار العميل كقناع لوني (mask)، يُستبدل بنفس الاسم.

## المحتوى والمشاهد
- المشهد الافتتاحي: علبة خاتم ثلاثية الأبعاد تُفتح تلقائيًا، ثم الضغط على الخاتم للدخول. يُحمَّل three.js عند الطلب فقط (lazy loading) لتسريع أول تحميل.
- بعد الافتتاحية: صفحة واحدة بتمرير عمودي طبيعي — قسم الأسماء والبسملة فوق، وورقة التفاصيل (تقويم الشهر، الوقت، المكان مع رابط خرائط، أزرار الرد) تحته. لا أزرار تنقل بين مشاهد.
- سهم تلميح صغير أسفل قسم الأسماء يختفي بعد أول سحب، ويتوقف تمامًا مع تقليل الحركة.
- زر واتساب اختياري لتلقي الردود (يظهر تلقائيًا عند تعبئة `whatsapp` في الإعداد).

## الرد على الدعوة
أُلغيت نافذة تأكيد الحضور نهائيًا، والاعتماد على زر الواتساب (`whatsapp` في الإعداد) برسالة جاهزة تتضمن الأسماء والتاريخ. لاستقبال الردود بأي طريقة أخرى مستقبلًا يمكن إضافة خدمة في `src/services/`.

## ملفات غير مستخدمة حاليًا (مرشحة للحذف أو إعادة التوظيف)
- `src/components/Ring3D.jsx` و`src/components/Monogram.jsx` غير مستوردين من أي مشهد.
- كتل CSS قديمة في `styles.css` (مثل `.welcome-*` و`.envelope-*` و`.page` و`.person`) لا يستخدمها أي عنصر حالي.
